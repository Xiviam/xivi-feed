# XIVI Feed

XIVI — самостоятельная фотосоцсеть в духе Instagram: публикуй кадры, собирай свою ленту и общайся без лишнего шума. Production-адрес: [feed.xivici.space](https://feed.xivici.space).

## Возможности

- общая лента и персональная лента подписок;
- профили, подписка/отписка, счётчики и сетка публикаций;
- загрузка JPG, PNG и WebP до 10 МБ;
- лайки, комментарии, сохранённые посты и нативный Share API;
- поиск по людям и подписям, включая русский регистр;
- уведомления о реакциях, комментариях, подписках и сообщениях;
- личные диалоги один на один с непрочитанными сообщениями;
- шифрование текста сообщений в SQLite через AES-256-GCM и HTTPS при передаче;
- светлая, тёмная и системная темы без вспышки неправильной темы;
- TOTP-двухфакторка, одноразовые recovery codes и защита от повторного кода;
- подтверждение email и восстановление пароля через Resend;
- жалобы на публикации и отдельная админ-панель;
- бан/разбан пользователей, отзыв их сессий и удаление постов модератором;
- журнал действий модерации, лимиты запросов и безопасные cookie-сессии;
- адаптивный интерфейс для телефона и компьютера.

> Шифрование переписки защищает текст в базе данных, но сейчас не является end-to-end: сервер расшифровывает сообщения для участников диалога. Полноценное E2E потребует клиентских ключей, управления устройствами и отдельного протокола восстановления.

## Стек

- React 19, TypeScript, Vite;
- Node.js 22, Express 5;
- встроенный `node:sqlite` без внешней СУБД;
- Docker Compose, NGINX, Let's Encrypt;
- Resend для транзакционных писем.

## Локальный запуск

Понадобятся Node.js 22.13+ и pnpm.

```bash
pnpm install
Copy-Item .env.example .env
pnpm dev
```

Открой `http://localhost:3000`. Для локальной демо-базы поставь `SEED_DATABASE=true`; тестовый вход: `kotleta.jpg` / `demo12345`.

## Переменные окружения

Шаблон лежит в `.env.example`. Для production обязательно замени:

- `TWO_FACTOR_ENCRYPTION_KEY` — 32 случайных байта в hex;
- `CHAT_ENCRYPTION_KEY` — другой независимый ключ на 32 байта;
- `ADMIN_USERNAME` — ник владельца админ-панели;
- `RESEND_API_KEY` и `RESEND_FROM` — настройки почтовой отправки;
- `PUBLIC_ORIGIN` и `CORS_ORIGIN` — публичный HTTPS-адрес.

Файл `.env`, база и загрузки исключены из Git. Потеря ключа чатов сделает старые сообщения нечитаемыми, поэтому production-ключ нужно хранить в менеджере секретов и резервной копии.

## Проверка

```bash
pnpm build
pnpm test
```

Сборка последовательно проверяет клиентский и серверный TypeScript. Healthcheck доступен по `/api/health`.

## Развёртывание

`docker-compose.yml` поднимает приложение на `127.0.0.1:4350`, а шаблоны в `deploy/` проксируют `feed.xivici.space` через NGINX. Данные сохраняются в Docker volume `xivi_feed_data`.

```bash
docker compose up -d --build
curl http://127.0.0.1:4350/api/health
```

После проверки приложения установи NGINX-конфиг, выпусти сертификат Let's Encrypt и включи HTTPS-шаблон.
